### nuzlocke.app (domtronn/nuzlocke.app, fork Bassel-T/nuzlocke.app)

- **What:** the ROM-hack game packs, generated by `scripts/import-nuzlocke-app.mjs` from the fork's generated data (`src/lib/data/routes.json`, `league.json`, `patches.json`) at commit `2b4f2ec`:
  - route lists and boss fights (`data/games/<hack>/routes.json`, `levelcaps.json`); the level caps are the highest level in each boss's team;
  - the hacks' stat and type changes (`data/shared/<hack>-species.json`) and move changes (`data/games/<hack>/move-overrides.json`);
  - the hacks' own Pokémon (`data/fakemon.json`): names, types, base stats and evolution lines only. Their sprites are not used: nuzlocke.app serves them from its own image host, which does not allow use by other sites.
- **Packs:** Renegade Platinum, Sacred Gold, Storm Silver, Blaze Black, Volt White, Blaze Black 2 / Volt White 2 Redux, Emerald Kaizo, Inclement Emerald, Rising Ruby, Sinking Sapphire, Glazed, New Generations, Radical Red, Unbound, Run & Bun, Blazing Emerald.
- **Source:** [github.com/Bassel-T/nuzlocke.app](https://github.com/Bassel-T/nuzlocke.app), a fork of [github.com/domtronn/nuzlocke.app](https://github.com/domtronn/nuzlocke.app).

### Pokémon Infinite Fusion (infinitefusion/infinitefusion-e18)

- **What:** the fan game's own values, read from the compiled data files of its public project repository, version 6.2.4, by the `scripts/generate-infinite-fusion-*.mjs` scripts. These are:
  - species stats, types, catch rates and weights (`data/shared/infinite-fusion-species.json`);
  - move lists, TM/HM and tutor compatibility;
  - trainer levels for the level caps.
- **Mechanics:** the capture formula and the ball list in `src/lib/catchrate.ts` are reimplemented from its Ruby scripts.
- **Ball icons:** the game's own ball icons are downloaded from that repository when a container starts. They are never stored in this repository.
- **Source:** [github.com/infinitefusion/infinitefusion-e18](https://github.com/infinitefusion/infinitefusion-e18)
- **License:** the repository does not state one. Only factual game values are used, and the project is credited in the app's menu while an Infinite Fusion run is open.

### Reference wikis

- **[PokéWiki](https://www.pokewiki.de/):** source for the German move names that changed between generations (`data/move-name-history.json`), and for the gym badges' official names in all five languages that no older pack carried (Kalos, Galar, Paldea and a few Hoenn and Unova badges; `data/shared/badge-names.json`, `scripts/generate-badge-names.mjs`), and for the official place names of every official game in all five languages (`data/shared/place-names.json`, `scripts/generate-place-names.mjs`; the hand-made `data/shared/place-name-overrides.json` cites the pages it used), read from the "In anderen Sprachen" table of each page - facts, no text copied.
- **[Bulbapedia](https://bulbapedia.bulbagarden.net/):** reference for the per-generation capture formulas and ball quirks in `src/lib/catchrate.ts`, and for verifying the historical base-stat corrections. The boss trainers' official names in German, French, Spanish and Italian for the packs imported from nuzlocke.app (`data/shared/trainer-names.json`, `scripts/generate-trainer-names.mjs`) are read from the "Names" tables of its character pages - facts, no text copied.
- **[pokemon-infinite-fusion.com](https://pokemon-infinite-fusion.com/):** used to check the Infinite Fusion gym leader levels.
- **[Infinite Fusion wiki](https://infinitefusion.fandom.com/):** used to check routes and locations.

All four were consulted for facts (names, numbers); no text or images were copied.
